# PARTIE 2 — STRATÉGIE MARKETING & ADS (Budget 500 €)

---

## 2.1 — Philosophie d'acquisition

**Principe directeur : convertir l'intention locale, pas créer une notoriété générale.**

À ce stade, l'objectif n'est pas de devenir une marque. C'est de trouver 27 clients par mois dans un rayon de 20 km. Chaque euro investi doit pouvoir tracer un retour direct en réservation.

**Stratégie en 3 couches :**
1. **Capturer l'intention existante** → Google Ads (mots-clés = quelqu'un qui cherche déjà)
2. **Interrompre et séduire** → Meta Ads (avant/après = preuve visuelle immédiate)
3. **Ancrage local direct** → Guérilla (flyers, B2B, bouche-à-oreille activé)

---

## 2.3 — GOOGLE ADS SEARCH (200 €)

### Stratégie

Google Search est le canal prioritaire car il capte des gens qui **cherchent activement** à faire nettoyer leur voiture. Taux de conversion nettement supérieur à Meta.

### Structure de campagne

**Campagne unique : "Nettoyage Auto Local"**

```
Groupe d'annonces 1 — Nettoyage intérieur
  Mots-clés :
  - "nettoyage voiture intérieur [VILLE]" [exact]
  - "nettoyage habitacle domicile [VILLE]" [exact]
  - "aspiration voiture domicile" [expression]
  - "nettoyage auto à domicile" [expression]

Groupe d'annonces 2 — Detailing / Shampouinage
  Mots-clés :
  - "detailing auto [VILLE]" [exact]
  - "shampouinage voiture [VILLE]" [exact]
  - "lavage auto domicile [VILLE]" [expression]
  - "nettoyage professionnel voiture" [expression]

Groupe d'annonces 3 — Concurrents / Alternatives
  Mots-clés :
  - "lavage auto pas cher [VILLE]" [expression]
  - "nettoyage voiture pas cher domicile" [expression]
```

### Exemples d'annonces

**Annonce 1 (axe prix + déplacement) :**
```
Titre 1 : Nettoyage Auto à Domicile — [Ville]
Titre 2 : Dès 45 € | On Se Déplace Chez Vous
Titre 3 : Réservez en 2 Minutes En Ligne
Description : Service de detailing mobile professionnel. Intérieur, 
shampouinage, formule complète. Disponible week-end. 
Devis immédiat → [URL]
```

**Annonce 2 (axe résultat visuel) :**
```
Titre 1 : Votre Voiture Comme Neuve — [Ville]
Titre 2 : Detailing Mobile | Sans Se Déplacer
Titre 3 : Avant/Après Garantis | Avis Vérifiés
Description : Aspirateur pro, shampouineuse, produits premium Koch 
Chemie. 3 formules adaptées. Résultat garanti ou retour gratuit.
```

### Paramétrage technique

```
Enchères         : CPC manuel → max 2,50 €/clic en démarrage
Budget journalier : 7 € (= 210 €/mois)
Ciblage géo      : Rayon 20 km autour de votre ville
Plages horaires  : Lun-Ven 12h-22h + Sam-Dim 8h-20h
Appareils        : Mobile priority (+20% ajustement)
Extensions       : Appel téléphonique + Liens annexes (Nos formules / Réserver)
Landing page     : Page /reserver du site (directement le tunnel)
```

### Mots-clés négatifs (obligatoires dès le départ)

```
- "formation"
- "cours"
- "emploi"
- "recrutement"
- "produit"
- "acheter"
- "matériel"
- "DIY"
```

## 2.4 — META ADS — Facebook / Instagram (200 €)

### Stratégie

Meta ne capte pas l'intention, il **l'interrompt**. Le levier est 100 % visuel : un avant/après bien filmé peut exploser organiquement. L'objectif est de créer l'envie chez quelqu'un qui n'avait pas encore pensé à faire nettoyer sa voiture.

### Phase 1 — NOTORIÉTÉ LOCALE (Semaines 1-2 : 80 €)

**Objectif** : Engagements + Portée locale
**Format** : Reel vertical 9:16, 15-30 secondes

**Structure du Reel modèle :**
```
0-3s  : "POV : t'as pas nettoyé ton intérieur depuis 6 mois 😂" 
         → plan macro sur moquette sale/cendres/miettes
3-12s : Timelapse accéléré du nettoyage (aspirateur, shampouineuse, microfibres)
12-20s: Révélation : avant/après côte à côte + zoom sur sièges propres
20-25s: "On se déplace chez toi → [VILLE] 📍 Dès 45€ | Lien en bio"
Musique: trending audio Instagram (à choisir selon l'actu)
```

**Ciblage :**
```
Localisation  : [Ville] + rayon 15 km
Âge           : 22-55 ans
Intérêts      : Automobile, entretien véhicule, nettoyage, 
                concessionnaires auto
Comportement  : Propriétaires de véhicule (si disponible)
Exclusions    : Personnes ayant déjà visité le site (retargeting séparé)
```

**Budget** : 5 €/jour × 16 jours = 80 €

---

### Phase 2 — CONVERSION + RETARGETING (Semaines 3-4 : 80 €)

**Objectif** : Trafic vers /reserver
**Format** : Carousel ou image statique "3 formules / 3 prix"

**Visuel carousel modèle :**
```
Carte 1 : Photo voiture intérieur impeccable + "EXPRESS INTÉRIEUR — 45€"
Carte 2 : Photo sièges shampouinés + "DEEP CLEAN — 85€"  
Carte 3 : Photo carrosserie brillante + "INTÉGRALE PREMIUM — 130€"
Carte 4 : CTA "Réservez en ligne → On vient chez vous" + URL
```

**Audience retargeting :**
```
- Personnes ayant visité le site (pixel Meta installé)
- Personnes ayant interagi avec les Reels Phase 1
- Lookalike 1% de la liste clients (dès qu'on a 20+ clients)
```

**Budget** : 5 €/jour × 16 jours = 80 €

---

### Phase 3 — Budget de réserve (40 €)

Garder 40 € pour booster un post organique qui performe naturellement (si un Reel avant/après dépasse 10K vues organiquement, le booster x5 sur la zone locale).

---

### Métriques à surveiller

| Métrique | Seuil d'alerte | Action si dépassé |
|---|---|---|
| CPM > 10 € | Mauvais | Restreindre le ciblage |
| CTR < 1,5 % | Mauvais | Changer le créatif |
| CPC > 0,80 € | Mauvais | Tester nouvelle accroche |
| Coût/réservation > 20 € | Stop | Pause + analyse |

## 2.5 — GUÉRILLA MARKETING & B2B (100 €)

### Flyers physiques (30 €)

**Production** : 200 flyers A5 recto-verso (Vistaprint ou imprimeur local)

**Zones de dépôt prioritaires :**
- Parkings de grandes surfaces (Leclerc, Carrefour, Intermarché) → glisser sur le pare-brise
- Résidences avec parking couvert → boîtes aux lettres ou tableau d'affichage
- Laveries automatiques de voiture (capter les gens déjà conscients du besoin)
- Stations-service

**Message flyer :**
```
[Recto - Grand titre]
Votre voiture mérite mieux qu'un lavage automatique.

[Prix bien visibles]
Intérieur Express    45 €
Deep Clean           85 €  
Intégrale Premium   130 €

On se déplace chez vous.
[QR Code vers /reserver]
[Numéro de téléphone]

[Verso]
Photo avant/après + logos "Koch Chemie" + "Matériel Pro"
+ Témoignages des 5 premiers clients (à ajouter dès que disponible)
```

---

### Partenariats B2B (gratuit — temps uniquement)

**Cibles prioritaires :**

1. **Comités d'entreprise (CE)** → Contacter les RH ou représentants CE des PME locales.
   - Pitch : "Intervention sur le parking de votre entreprise, vos employés profitent d'un tarif préférentiel -15%, on peut traiter 4-5 voitures en une journée."
   - Fréquence : 1 journée/mois dans une entreprise = 4-5 voitures garanties

2. **Concessionnaires automobiles** → Proposer service de préparation de véhicules d'occasion.
   - Pitch : "Nous préparons vos VO avant livraison à partir de 60 € pour un résultat showroom."
   - Volume potentiel : 5-10 voitures/mois si 1 concessionnaire partenarial

3. **Garages & centres auto** → Sous-traitance nettoyage après réparation.
   - Pitch : "Vos clients récupèrent leur voiture propre, vous proposez une prestation premium sans investissement."

4. **Agences immobilières** → Nettoyage de véhicules des agents (Fleet).
   - Contact : Email + appel à la direction commerciale

**Template email B2B :**
```
Objet : Partenariat detailing mobile — Service pour vos [employés/véhicules]

Bonjour [Prénom],

Nous sommes une équipe de detailing automobile mobile basée à [Ville].
Nous proposons un service professionnel directement sur site.

Ce qui peut vous intéresser :
→ Tarif partenaire : -15% sur toutes nos formules
→ Intervention sur votre parking (0 contrainte pour vos [employés/clients])
→ Avant/Après garantis avec photos

Nous serions ravis d'organiser une première journée découverte gratuite
pour 2 véhicules de démonstration.

Disponibles pour en discuter rapidement,
[Prénom + Numéro]
```

---

### Bouche-à-oreille activé (gratuit)

- **Programme parrainage** : "Ramenez un ami = 10 € de réduction sur votre prochaine prestation"
- **Google My Business** : Créer la fiche immédiatement (gratuit, essentiel pour le SEO local)
- **Demande d'avis Google** : Envoyer un SMS après chaque prestation avec le lien direct vers la fiche
- **Groupes Facebook locaux** : Poster avant/après dans les groupes "Bons plans [Ville]", "Entraide [Ville]"
